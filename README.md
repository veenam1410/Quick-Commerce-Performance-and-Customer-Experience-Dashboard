# 🛒 Quick Commerce Performance & Customer Experience Dashboard

An interactive **Quick Commerce Analytics Dashboard** built using **Microsoft Excel** to analyze sales performance, customer behavior, delivery operations, payment preferences, and customer experience across multiple platforms, cities, product categories, and time periods.

---

## 📌 Project Description

This project demonstrates an end-to-end data analytics workflow using two separate quick-commerce datasets.

The datasets were imported into **Power Query**, cleaned and transformed, and then integrated by creating and matching index fields. The consolidated dataset was used to develop KPIs, Pivot Tables, Pivot Charts, and interactive slicers in Microsoft Excel.

The final dashboard provides a consolidated view of business performance and operational efficiency while allowing users to explore different segments using interactive filters.

## 📂 Data Sources

This project uses two publicly available datasets from Kaggle.

### Dataset 1 - Quick Commerce Dataset

Contains quick-commerce transaction information covering orders, customers age and location, products, delivery, payment methods, ratings, and other operational attributes.

**Source:**
[Quick Commerce Dataset - Kaggle](https://www.kaggle.com/datasets/rohitgrewal/quick-commerce-dataset)

### Dataset 2 - E-Commerce Analytics: Swiggy, Zomato, Blinkit

Contains quick-commerce order and service-related information across platforms including Blinkit, Swiggy Instamart, and JioMart.

**Source:** 
[Blinkit, Swiggy & JioMart Orders Dataset - Kaggle](https://www.kaggle.com/datasets/logiccraftbyhimanshi/e-commerce-analytics-swiggy-zomato-blinkit)

### Data Integration

The two datasets were:

1. Imported into Power Query
2. Cleaned and standardized
3. Prepared with corresponding index/key fields
4. Merged using the index fields
5. Transformed into a consolidated dataset
6. Loaded into Excel for analysis and dashboard development

---

## 🔍 Key Business Insights

- Customers aged **41–60** represent the largest customer segment, indicating strong quick-commerce adoption among mature customers.
- Order activity varies across days and hours, highlighting distinct demand patterns throughout the week.
- Delayed orders are distributed across different delivery-distance ranges, highlighting distance as an operational factor to monitor.
- Product category preferences vary across the customer base, creating opportunities for category-specific inventory planning.
